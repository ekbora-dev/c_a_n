# C.A.N : Compagnie alsacienne de navigation

Ce projet d'étude consiste à prendre réservation pour une traversée sur un terminal codé en C# et d'afficher cette réservation sur le site codé en HTML, CSS et JavaScript

- Le dossier "Programmation" est la partie réservation (C#)
- Le dossier "Web" est la partie affichage de la réservation

Le site Web permet également d'afficher d'autres réservation sur une certaine période, ou de regarder les statistiques (nombre de réservation...)
